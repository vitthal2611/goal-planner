# 🚀 Quick Start: Smart Categorization

## 3-Step Setup (Takes 2 minutes!)

### Step 1: Import Your Transactions
```
1. Click Profile button (top right)
2. Go to Settings tab
3. Scroll to "CSV Import"
4. Click "Upload File" or "Paste Data"
5. Import your bank statement
```

### Step 2: Categorize Common Vendors
```
1. Go to Transactions tab
2. Find "SAMRUDDHI SNACKS" (or any vendor)
3. Double-click the category column
4. Select "Eatout" from dropdown
5. System learns: "SAMRUDDHI SNACKS" → "Eatout" ✅

Repeat for 5-10 common vendors:
- PANKAJ HARDWARE → Shopping
- SMART BAZAAR → Groceries
- FLIPKART → Shopping
- GOOGLE → Subscriptions
```

### Step 3: Apply to All Existing Transactions
```
Option A - From Transactions Tab (Quick Access):
1. Click "✨ Auto-Categorize" button (top of transactions list)
2. Review preview
3. Confirm
4. Done! 🎉

Option B - From Profile:
1. Click Profile button
2. Scroll to "🤖 Smart Categorization"
3. Click "✨ Apply to Existing"
4. Review preview
5. Confirm
6. Done! 🎉
```

## Troubleshooting

### "No learned mappings yet"
**Solution:** Assign categories to at least one vendor first
1. Go to Transactions tab
2. Double-click category cell
3. Select category
4. Try again

### "No matching vendors found"
**Solution:** The uncategorized transactions don't match any learned vendors
- Check vendor names (must match exactly)
- Categorize more common vendors
- Try again

### Wrong category assigned
**Solution:** Just fix it!
1. Double-click the category
2. Select correct category
3. System learns the new mapping
4. Future transactions will use correct category
