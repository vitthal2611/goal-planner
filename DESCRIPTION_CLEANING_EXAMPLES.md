## Special Cases

### ATM Withdrawals
```
ATM WDL 123456 PUNE MAHARASHTRA
→ ATM Withdrawal
```

### Card Transactions
```
POS RELIANCE DIGITAL PUNE 1234
→ RELIANCE DIGITAL PUNE

CARD TXN AMAZON INDIA 5678
→ AMAZON INDIA
```

### Long Descriptions (>50 chars)
```
VERY LONG DESCRIPTION WITH LOTS OF DETAILS AND CODES AND NUMBERS 123456789
→ VERY LONG DESCRIPTION WITH LOTS OF DETAI...
```

## Pattern Recognition

### UPI Pattern
```
UPI-[VENDOR NAME]-[details@bank-codes-numbers]
     ^^^^^^^^^^^
     Extracted!
```

### NEFT Pattern
```
NEFT CR-[BANK]-[COMPANY NAME]-[details]
                ^^^^^^^^^^^^^
                Extracted!
```

## Benefits

✅ **Cleaner UI** - Short, readable transaction names
✅ **Easy Categorization** - Vendor name is clear
✅ **Better Search** - Find transactions by vendor
✅ **Consistent Format** - All descriptions follow same pattern
✅ **Automatic** - No manual editing needed

## Customization

If you want to keep full descriptions, you can:
1. Edit after import (double-click in Transactions tab)
2. Or modify the `cleanDescription()` function in `data-manager.js`
